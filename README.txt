HOW TO ADD GITHUB AND LINKEDIN
1. Open index.html in VS Code.
2. Press Ctrl+F, and search for: const GITHUB_URL
3. Replace the empty quote pairs with your actual URLs.
   const GITHUB_URL = "https://github.com/your-username";
   const LINKEDIN_URL = "https://www.linkedin.com/in/your-profile/";
4. Save the file (Ctrl+S), then reload the browser page.
5. Both links appear in the navigation, homepage, contact section and footer.

Until you add the URLs, clicking a social link displays a setup message rather than sending visitors to a nonexistent profile.

To publish, upload index.html to a GitHub Pages repository, or deploy with a static site host.
